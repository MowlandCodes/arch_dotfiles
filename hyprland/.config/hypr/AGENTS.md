# Hyprland Config — AGENTS.md

Wayland secondary environment for [arch_dotfiles](https://github.com/mowlandcodes/arch_dotfiles). Catppuccin Macchiato theme.

## Source graph

`hyprland.lua` is the entry point (Hyprland >= 0.55 Lua config). It `require()`s each module:

```
hyprland.lua
├── plugins.lua        — split-monitor-workspaces Lua package (smw.setup)
├── environment.lua    — env vars (NVIDIA, cursor, etc.)
├── macchiato.lua      — Catppuccin Macchiato color table (hex values)
├── variables.lua      — local vars (terminal, browser, menu, etc.)
├── monitors.lua       — auto-generated by nwg-displays (do not edit manually)
├── autostart.lua      — hl.on("hyprland.start") autostart entries
├── look_n_feel.lua    — hl.config() for general, decoration, animations, misc
├── workspaces.lua     — hl.window_rule() calls (floating, sizing, etc.)
└── keybinds.lua       — hl.bind() calls, uses smw for workspace cycling
    └── requires plugins.lua (smw) + variables.lua
```

Old `.conf` files kept as-is (backup). `hyprlock.conf` and `hyprpaper.conf` remain `.conf` (not migrated).

## File types

| Extension | What |
|---|---|
| `.conf` | Legacy hyprlang config (backup, not actively loaded) |
| `.lua` | Hyprland Lua config (hl namespace) |
| `.sh` in `scripts/` | Shell helpers sourced by keybindings |

## Theme

Catppuccin Macchiato colors defined in `macchiato.lua` (raw hex in `M.*`, use `M.rgb(name)` or `M.rgba(name, alpha)`). Accent: mauve `#c6a0f6`. Font: `JetBrainsMono Nerd Font` throughout.

## Plugin

`split-monitor-workspaces` at `plugins/split-monitor-workspaces/` (Lua package, not C++ plugin). Configured in `plugins.lua` via `smw.setup()`. Dispatchers exported: `smw.workspace(n)`, `smw.cycle_workspaces(dir)`, `smw.move_to_workspace(n)`, `smw.move_to_workspace_silent(n)`.
